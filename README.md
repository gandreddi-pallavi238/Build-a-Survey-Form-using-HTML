# 📝 Student Survey Form (HTML & CSS)

This project is a Student Survey Form created as part of the GeeksforGeeks Skill Up – Full Stack Web Development (Day 7) learning track.
It demonstrates the use of HTML forms and external CSS styling to collect user information in a structured and user-friendly way.

# ✨ Features

Student details input (Name, Age, Email)

Gender selection using radio buttons

Multiple course selection using checkboxes

Dropdown for highest qualification

Feedback section using textarea

Clean and responsive UI with external CSS

Beginner-friendly and well-structured code

# 🛠️ Technologies Used

HTML5 – Form structure and input elements

CSS3 – Styling and layout (external stylesheet)

# 📂 Project Structure
Student-Survey-Form/
│
├── index.html
├── style.css
└── README.md

# ▶️ How to Run

Download or clone the repository

Open index.html in any web browser

Fill and submit the survey form

# 🎯 Learning Outcome

Understanding HTML form elements

Using radio buttons, checkboxes, select, and textarea

Linking and applying external CSS
